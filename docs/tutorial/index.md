# Tutorial

Learn the library step by step. Each page builds on the previous one, and
every block of code runs.

| Step | You learn |
|---|---|
| [Problem and direction](problem.md) | describe what you want to solve, and minimize or maximize |
| [Constraints](constraints.md) | reject, repair or penalize infeasible solutions |
| [Stopping](stopping.md) | iterations, evaluations, time and target stops |
| [Operators](operators.md) | how neighborhoods, selection, crossover and mutation plug in |
| [Genetic Algorithm](genetic-algorithm.md) | population-based search |
| [Simulated Annealing](simulated-annealing.md) | single-trajectory search |
| [Results and history](results.md) | read the result and plot convergence |
| [Reproducibility](reproducibility.md) | get the same run twice |

!!! tip
    In a hurry? The [worked examples](../examples.md) solve Knapsack and TSP
    start to finish.
